คู่มือขั้นตอนการนำแอปพลิเคชันขึ้นใช้งานบน GitHub Pages

นักวิชาการสาธารณสุขสามารถนำไฟล์ Dashboard นี้ไปเปิดให้บริการบนอินเทอร์เน็ตแบบฟรีและปลอดภัยได้ง่ายๆ ผ่าน GitHub Pages โดยทำตามขั้นตอนดังนี้:

1. สร้าง Repository

สมัครสมาชิก GitHub และสร้าง Repository ใหม่ ตั้งชื่อเช่น covid-dashboard และตั้งค่าเป็น Public

2. อัปโหลดไฟล์

นำไฟล์ HTML นี้มาตั้งชื่อไฟล์ว่า index.html แล้ว Upload เข้าไปใน Repository หลัก (main branch)

3. เปิดใช้งาน Pages

ไปที่ Settings > Pages ใน Build and deployment เลือก Source เป็น Deploy from a branch และเลือก main / root

4. เข้าใช้งาน Web App

รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น https://username.github.io/covid-dashboard พร้อมใช้งานทันที
